# 资金政策：什么能复利，什么不能

> 写于 2026-11-12。本文档的唯一目的是防止把测试网数字当成钱，并给出真钱到账后的处置规则。

## 1. 结论先行

**50 tUSD8 不能当启动资金。它值 0 美元。**

三条硬事实：

1. **没有兑换路径。** tUSD8 是 QDay Aevum 测试网的 `FiatToken`：`mint()` 只有 minter 能调（"caller is not a minter"），faucet 的 dispenser `0x4551B2a3…` 只接受 relayer 调用。唯一能拿到它的方式就是主办方空投。没有 DEX、没有桥、没有 CEX 挂单。
2. **不能跨链。** 它到不了 Base，换不成 USDC、USDT，也付不了 gas（gas 用 tQDAY）。
3. **算成收入就是造假。** 任何评审点一下区块浏览器就能看到 token 地址和链 ID。把 $805 的测试币流水写成营收，等于自己取消资格。

所以本文档后面所有"复利"讨论，都建立在**真钱**上；测试币只承担一个职能：**买证据**。

## 2. 这 50 tUSD8 真正买到的三样东西

| 买到的东西 | 为什么值钱 |
|---|---|
| **评奖证据** | 挑战赛奖金 $800 / $500 / $200 USDT 是 30 天内唯一够得着的真钱。真实结算记录直接决定名次。 |
| **gas 边界** | 定价能不能成立，取决于一笔 $0.05 的销售要烧多少 gas。这个数字只能在链上测，不能猜。 |
| **资本周转率** | 固定 float 在 1% take 下能承载多少流水 —— 这是支付类项目最硬的技术指标之一。 |

### 3.2 同一笔 float 的周转能力

| 指标 | 数值 |
|---|---|
| 结算笔数 | **988** |
| 累计流水 | **805.40 tUSD8** |
| 周转倍数（流水 / 工作 float 47.95） | **16.80x** |
| 系统 float（start → end） | **50.000000 → 50.000000（100.00% 守恒）** |
| 佣金（离开 float 进账本） | 8.054（house 7.212224 / referrer 0.8018 / treasury 0.039976） |
| gas 总量 | **26,153,629 gas = 0.026153629 tQDAY** @ 1 gwei |
| 每笔平均 gas | 26,471（含 1/2 笔这种极端低效批量） |
| 账本不变量 | **PASS**，router 0.000000 == accounted 0.000000 |

**关键结论：tUSD8 一枚不少。** gas 用 tQDAY 付，佣金留在账本里再出账，所以系统内 tUSD8 从 50.000000 到 50.000000 完全守恒。真正稀缺的资源是 gas，不是余额 —— 26 万笔/1 tQDAY 量级。

> **数据更正**：初次运行时脚本用"单一钱包余额差"算 gas，把给两个操作钱包的 2 tQDAY 充值也算进去了，同时"剩余 float"只统计了一个钱包（63.80%）。已用 `scripts/reconcile-float-benchmark.js` 从 50 张收据和全地址余额重新核算，上表为修正值；原始错误字段在 JSON 里用 `supersededFields` 标记。

<!--/BENCHMARK-->

**怎么读这组数：**

- 1% take 意味着每 1 美元周转只有 1 美分离开 float，99% 在同一笔交易里回到 payee。所以 **float 不是被消耗掉的，是被反复使用的**。
- 真正限制吞吐的不是余额，是 gas：批量 100 时每笔 22,682 gas，边际 21.7k。
- 佣金没有消失，它按 90/10 + 0.5% 进了 house / referrer / facilitator 三条独立账本，最后真实出账到三个不同地址。
- 一枚 tUSD8 都没少：系统内 50.000000 → 50.000000。唯一被消耗的是 tQDAY gas（0.0262 枚）。

**不要这样读：** 这 805 美元不是客户付的钱。每笔交易的两端都是我们自己的钱包，它证明的是"这条轨道能扛多少流水"，不是"有多少人愿意付钱"。
