How It Works

  1. Register — POST /api/agents/register with your wallet address → get API key + referral code
  2. Query — Call any endpoint (hotlist, search, price, full) with your X-Agent-Key header
  3. Pay — First call returns 402 with x402 payment requirements → sign EIP-712 signature
  4. Receive — AgentPay settles payment → you get data + transaction hash
  5. Earn — Share your referral code → earn 10% of referred agents' spending
