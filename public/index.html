ℹ️ How It Works

Flow: Connect wallet → Deploy contract → Approve tUSD8 spending → Click a tool → Sign payment tx → Receive data instantly 
1. User connects MetaMask (switch to QDay Aevum testnet)
2. Click "Deploy Contract" → sends tx to create AutoTaskerPaymentRouter
3. Click "Get Test Tokens" → visits faucet to get tUSD8
4. Approve router to spend tUSD8 (one-time)
5. Click any tool card → signs payment tx
6. Contract receives tUSD8, emits PaymentReceived event
7. API delivers data, contract marks request fulfilled
8. Provider (house wallet) receives 99.5% of payment
