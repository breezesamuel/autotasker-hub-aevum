## 二、抖音：3 条短视频脚本（每条 30–45 秒）

### 脚本 1｜痛点型：「客户只要 50 台，工厂不接单」

- **0–3s 画面**：桌上摊着图纸，手把图纸推远
- **口播**："客户只要 50 台，问了三家工厂，都说起订量 1000。"
- **3–15s**：镜头切到工作台，拿起一块小板子
- **口播**："我们做的是这种单：50 台也开模、也打样、也做老化测试。软件、后台、小程序一起给。"
- **15–30s**：屏幕上放 BOM 表和排期表
- **口播**："样机 7–10 天，小批量 3 周。方案先给，价格后谈。"
- **结尾 3s**：字幕「私信『打样』领方案模板」
- **标题**：`客户只要50台，工厂不接单怎么办`
- **话题**：#硬件创业 #小批量定制 #打样 #产品开发 #供应链

### 脚本 2｜对比型：「三种做法，成本差 4 倍」

- **0–3s**：白板写「方案A / 方案B / 方案C」
- **口播**："同样一个采集终端，三种做法，成本差 4 倍。"
- **3–25s**：逐个划掉
  - A：买现成模块 + 外壳 3D 打印 → 单价高，不能量产
  - B：全部自研 → 周期 6 个月，前期投入大
  - C：公版核心板 + 定制底板 + 定制固件 → 2 个月出量产版
- **25–35s**："大部分项目该走 C。我们把 C 的坑都踩过了。"
- **结尾**：字幕「私信『方案C』拿选型清单」
- **标题**：`同一个产品，三种做法成本差4倍`
- **话题**：#硬件设计 #嵌入式 #产品经理 #创业避坑

### 脚本 3｜数据型：「我们还能给你数据」

- **0–3s**：手机屏幕滑过一排排热搜榜
- **口播**："做硬件的，也得知道市场在热什么。"
- **3–20s**："微博热搜、抖音热点、电商价格、招投标、海关编码——这些我们做成接口，按次调用，几毛钱一次，不用买年费。"
- **20–35s**："硬件 + 数据，一套人给你做完。"
- **结尾**：字幕「私信『数据』看接口清单」
- **标题**：`硬件之外，我们还给你一份市场数据接口`
- **话题**：#数据分析 #跨境电商 #选品 #API

**发布节奏**：每周 3 条，固定周一/周三/周五 19:30 发。前 10 条不要带任何价格。

## 三、小红书：3 篇图文（首图 + 正文）

### 笔记 1｜「打样避坑清单」（收藏型，最容易起量）

**首图文案**：`打样前必须问工厂的 8 个问题`
**正文**：

```
做过 30+ 个项目，把打样踩过的坑整理成 8 个问题，直接拿去问工厂👇

1. 模具费含不含修改？改几次？
2. 打样费能不能抵量产？
3. 老化测试做几小时？报告给不给？
4. BOM 里有没有停产料？替代料是谁定的？
5. 固件能不能烧录后锁定？防抄板做到什么程度？
6. 小批量和大货是不是同一条产线？
7. 良率承诺是多少？不良品怎么算？
8. 交期延误的赔付条款写在哪？

第 5 条最容易被忽略，也是后面被抄得最惨的地方。

需要这份清单的表格版，评论区打「清单」，我发你。
```

**话题**：#硬件创业 #打样 #产品开发 #创业避坑 #供应链管理

### 笔记 2｜「从图纸到量产的时间表」

**首图文案**：`一张图看懂：图纸 → 样机 → 量产`
**正文**：

```
很多人以为找个工厂就能做产品，其实中间有 6 个节点：

① 需求冻结（1 周）：功能、成本、认证先定死，后面不再加
② 原理图 + PCB（2 周）
③ 打样 + 焊接（1 周）
④ 固件联调 + 老化（2 周）
⑤ 小批量试产 50 台（2 周）
⑥ 量产爬坡（3–4 周）

总共 10–12 周。任何一步说"3 天搞定"的，基本是在赌。

我们做 ①③④⑤ 这四段最多，因为最容易出问题。
有项目想对一下时间表的，评论区留「时间表」。
```

**话题**：#硬件工程师 #PCB设计 #量产 #项目管理

### 笔记 3｜「小批量也能做」的软广

**首图文案**：`50 台起做的硬件定制，长什么样`
**正文**：

```
经常有人问：我只想做 50 台，是不是没人接？

能接。关键是换成"公版核心 + 定制外围"的思路：
· 核心板用成熟方案，省掉 80% 的验证成本
· 底板按你的接口定制，开一次模
· 固件按你的协议改，OTA 预留好
· 外壳 3D 打印先验证，量起来了再开钢模

50 台的单价会比 5000 台贵，但比"全自研"便宜得多，而且能先拿到客户反馈。

我们现在接这类单：样机 7–10 天，小批量 3 周。
需要的私信「打样」，先给方案再谈价。
```

**话题**：#小批量定制 #硬件创业 #独立开发者 #产品落地

**发布节奏**：每周 2 篇，周二 / 周六 20:00。首图统一用同一套字体和留白，形成识别度。

## 四、评论区 / 私信的标准回复（照抄，别自由发挥）

| 用户说 | 回复 |
|---|---|
| 「多少钱」 | 「看具体方案，先确认 3 件事：做什么功能、多少台、什么时候要。私信我，10 分钟能聊完，然后给你报价区间。」 |
| 「能做 XX 吗」 | 「可以聊。发一张手绘草图或参考链接就行，不用完整图纸。我们先判断可行性，能做的给你排期。」 |
| 「太贵了」 | 「理解。50 台的单价确实高，因为分摊成本。如果你的量能到 300 台以上，单价能降一档，我可以按两个量级分别报给你。」 |
| 「有案例吗」 | 「有，但都是客户的项目，不能公开细节。可以给你看脱敏的结构图和测试报告。」 |
| 「你是工厂还是中介」 | 「我们是方案方，自己有工程和固件团队，产线是长期合作的。所以出了问题是找我们，不是让你去和工厂扯皮。」 |

**禁止回复**：「保证」「绝对」「全网最低」「百分百」——平台会限流，也容易引起纠纷。
